# Conceptual Materials Creation

This folder contains base documentation and prototype code for processing microfibers and creating a fiber-reinforced composite concept.

## Goals

- document the reactive UHTC matrix concept;
- provide a fiber processing prototype for small-diameter fibers;
- connect geometry, materials and manufacturing concepts in a dedicated folder.
