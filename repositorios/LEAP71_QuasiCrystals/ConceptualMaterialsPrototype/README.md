# Conceptual materials prototype

This folder contains a small C# prototype for exploring a 3D fiber-reinforced composite concept inspired by the quasicrystal and UHTC material framework.

## Goals

- model a fine 3D fiber network with smaller fibers;
- assign a reactive ceramic matrix concept based on ZrB2, SiC and TaB2;
- define a simple zonation strategy for skin, transition and core regions;
- provide a scaffold that can later be connected to PicoGK voxels or lattices.
