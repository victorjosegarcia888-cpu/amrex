# Arquitectura estructural: del laminado 2D al interlock 3D

## Hipótesis de diseño

En un laminado tradicional, el fallo suele iniciarse en interfaces entre capas. Bajo gradientes térmicos altos o cargas mecánicas severas, aparecen tensiones interlaminares que favorecen la microfisuración y la delaminación.

La propuesta aquí es reemplazar esta lógica por una arquitectura que no dependa de capas planas, sino de un entrelazado continuo en tres dimensiones. El objetivo es que una grieta o una fisura no encuentre un plano débil fácil de separar, sino una red de puentes estructurales que la detengan de forma controlada.

## Relación con los quasicristales

Los quasicristales presentan una organización ordenada pero no periódica. Esa propiedad es interesante porque evita la existencia de un patrón repetitivo simple que pueda concentrar tensiones de forma sistemática. En términos de diseño conceptual:

- la red no se basa en una repetición simple de celdas;
- las conexiones entre elementos pueden ser múltiples y no triviales;
- la arquitectura cuenta con una distribución de carga más dispersa;
- las rutas de propagación de fisuras se vuelven más complejas.

## Aplicación conceptual

Un componente estructural puede imaginarse como:

1. un núcleo formado por una malla aperiódica de quasicristales;
2. una piel externa densa para protección térmica;
3. una transición gradual entre ambos dominios para evitar interfaces abruptas.

Este enfoque sirve de inspiración para estructuras que deban resistir

- choque térmico;
- oxidación agresiva;
- esfuerzos de tracción y compresión complejos;
- deformación localizada sin fallo catastrófico.
