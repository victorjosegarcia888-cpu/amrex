# Conceptos avanzados de quasicristales para estructuras aeroespaciales

Esta carpeta recoge una propuesta de trabajo que conecta los quasicristales generados por esta librería con ideas de arquitectura estructural, química de materiales y procesos de fabricación para componentes de alto rendimiento.

## Contenido

## Objetivo

Sirve como punto de partida para explorar cómo una geometría aperiódica, generada mediante quasicristales y patrones de Penrose, puede inspirar estructuras resistentes a delaminación, choque térmico y degradación química.
