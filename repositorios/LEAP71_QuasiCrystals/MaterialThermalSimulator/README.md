# Material Thermal Simulator

This folder contains a prototype C# thermal simulator for materials analysis.

## Purpose

- simulate heat conduction in a simplified graded material system;
- support reactive matrix stages for UHTC concepts;
- provide a small C# framework for future extension to real thermal modeling.

## Contents

- `ThermalSimulator.cs`
- `ThermalMaterial.cs`
- `ThermalSimulationExample.cs`
