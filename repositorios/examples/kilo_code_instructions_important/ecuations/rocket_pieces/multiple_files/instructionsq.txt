1. CICLO TERMODINÁMICO (FFSC)
-----------------------------------------------------------
- Preburner fuel-rich (CH4)
- Preburner oxidizer-rich (O2)
- Ambos gases entran calientes a la cámara
- 2 turbobombas independientes (dual-shaft)
- Cavitación reducida por propulsante subenfriado
- Mejor mezcla y mayor eficiencia térmica

11. ECUACIONES PARA SCRIPTS FFSC
-----------------------------------------------------------

// Mezcla
O_F = mdot_ox / mdot_fuel = 3.6

// Presión de cámara
Pc = 330e5

// Empuje
F = mdot_total * Ve + (Pe - Pa) * Ae

// Isp
Isp = Ve / g0

// Perfil Bell
R(x) = a0 + a1*x + a2*x^2 + a3*x^3

// Canal helicoidal
r(t) = R * cos(t)
z(t) = pitch * t

Procedimiento completo para desarrollar un motor FFSC estilo Raptor
(con parámetros oficiales y materiales SX300/SX500)

1
Extraer parámetros oficiales del Raptor
Start Here
Estos parámetros son la base geométrica y termodinámica del motor FFSC.

Empuje SL: 230–250 tf (Raptor 2/3)

Empuje VAC: 258–275 tf

Presión de cámara: 330–350 bar

Isp SL: 327 s

Isp VAC: 350–380 s

Flujo másico total: 650 kg/s

Mezcla O/F: 3.6 : 1 (78% O₂, 22% CH₄)

Geometría de tobera: 34.34:1 (SL), 80:1 (VAC)


2
Definir geometría FFSC para PicoGK
Geometry
Convierte los parámetros del Raptor en perfiles Bell y cámaras FFSC.

Usar ShapeKernel.CreateBellNozzleProfile(Dc, Dt, De, θ_in, θ_exp, θ_exit)

Cámara: Dc=1.3 m, Dt=0.198 m

Tobera SL: De=0.62 m

Tobera VAC: De≈1.5 m

Ángulos Bell: 25° / 34° / 10.5°

Inyectores coaxiales swirl: 24–36 unidades

Preburners: ORPB + FRPB

Turbopumps: dual-shaft, flujo 650 kg/s

3
Integrar materiales y fabricación
Materials
El Raptor usa superaleaciones avanzadas y fabricación aditiva.

Material = InconelSX500; NozzleThroatMaterial = UHTC;

Inconel SX300/SX500 para manifolds

Inconel A286 para turbobombas

UHTC para garganta de tobera

40% del motor impreso en 3D (inyectores, turbobombas)

Aplicar metadatos de material en cada módulo

4
Construir módulos FFSC en C#
Coding
Cada módulo se implementa como un Task independiente.

Usar GKVoxelGrid, GKBoolean.Union/Subtract, HelixHeatX.CreateHelicalChannel()

BuildIgniter(): electrodos + cámara de ignición

BuildPreburnerORPB(): cilindro + manifold toroidal

BuildPreburnerFRPB(): geometría coaxial

BuildTurbopump(): impeller NASA TM X‑419 + housing

BuildCombustionChamber(): perfil Bell + lattice

BuildNozzle(): tobera SL/VAC + cooling

BuildCoolingChannels(): HelixHeatX helicoidal

5
Aplicar refrigeración regenerativa
Thermal
El Raptor usa canales helicoidales impresos en 3D.

channel = HelixHeatX.CreateHelicalChannel(width, depth, helixAngle, length)

Crear 120 canales helicoidales

Helix angle: 35°

Pitch adaptado a longitud de cámara

Boolean.Subtract para vaciar canales

Añadir manifold toroidal de entrada/salida

6
Añadir lattice y quasicristales
Advanced
Refuerzos internos tipo LEAP71 para vibración y calor.

vox.Modulate(QuasicrystalField.Penrose(order, amplitude, frequency))

Lattice TPMS Gyroid para paredes

Quasicrystal Penrose para refuerzo stealth

Aplicar Modulate() sobre el volumen

Mantener espesores 2–4 mm

7
Ensamblar el motor FFSC completo
Assembly
Combina todos los módulos en un solo volumen voxelizado.

Library.ExportMeshToStl(mesh, "FFSC_Raptor3.stl")

engine.Add(Chamber)

engine.Add(Nozzle)

engine.Add(Preburners)

engine.Add(Turbopumps)

engine.Add(Injectors)

engine.Subtract(CoolingChannels)

Aplicar filtros: Offset ±0.003, GaussianBlur(1.0)
