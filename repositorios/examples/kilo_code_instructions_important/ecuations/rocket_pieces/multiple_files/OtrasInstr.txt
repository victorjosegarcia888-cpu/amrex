🧱 2. Instrucciones específicas para cada repositorio Leap71
PicoGK (núcleo geométrico)
El agente debe usar:

GKShape.Cylinder(radius, height)

GKShape.Cone(r1, r2, height)

GKShape.Sphere(radius)

GKShape.Box(size)

GKMesh para superficies

GKVoxelGrid(resolution) para voxelizar turbobombas y cámaras

GKExport.SaveSTL(shape, filename)

PicoGK.Geometry (geometría avanzada)
El agente debe usar:

GKCurve para trayectorias de igniter

GKExtrude para crear canales

GKLoft para transiciones cámara → tobera

GKBoolean.Union/Subtract/Intersect

LEAP71_ShapeKernel (superficies paramétricas)
El agente debe usar:

Nurbs.CreateCylinder()

Nurbs.CreateCone()

Nurbs.CreateTorus()

Nurbs.CreateHelix()

Surfaces.Offset()

Solids.Thicken()

LEAP71_LatticeLibrary (rejillas internas)
El agente debe usar:

LatticeBuilder.WithCellSize()

LatticeBuilder.WithPattern(LatticePattern.Diamond)

LatticeBuilder.WithTPMS(TPMS.Gyroid)

ApplyTo(shape)

Para:

Cámara FFSC

Tobera

Carcasa de turbobomba

LEAP71_QuasiCrystals (estructuras avanzadas)
El agente debe usar:

QuasicrystalField.Penrose()

QuasicrystalField.AmmannBeenker()

ApplyToVolume(voxelGrid)

Para:

Refuerzos internos

Zonas de alta temperatura

Estructuras anti-vibración

LEAP71_HelixHeatX (refrigeración helicoidal)
El agente debe usar:

HelixHeatX.CreateChannel(radius, pitch, turns)

HelixHeatX.ApplyTo(chamber)

Para:

Refrigeración de cámara

Refrigeración de tobera

Refrigeración de prequemador

PicoGK_Examples (referencias de estilo)
El agente debe seguir:

Estructura de Tasks

Uso de Library.Go()

Exportación STL

Organización modular

🧩 4. Instrucciones para Program.cs
El agente debe generar:

csharp
using PicoGK;
using EngineFFSC;

class Program
{
    static void Main(string[] args)
    {
        FFSC_Engine engine = new FFSC_Engine();

        engine.BuildIgniter();
        engine.BuildPreburners();
        engine.BuildTurbopumps();
        engine.BuildCombustionChamber();
        engine.BuildNozzle();
        engine.BuildCoolingChannels();

        engine.Assemble();
        engine.Export("FFSC_engine_full.stl");
    }
}
