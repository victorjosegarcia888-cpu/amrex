1. REGLAS ARQUITECTÓNICAS CRÍTICAS DE PICOGK (OBLIGATORIAS)
--------------------------------------------------------------------------------
[R1] MALLAS ESTANCAS (WATERTIGHT / 2-MANIFOLD):
     Cualquier objeto 'Mesh' que se convierta a 'Voxels' mediante 'new Voxels(mesh)'
     DEBE ser una malla cerrada de caras compuestas por triángulos. Todos los 
     cilindros, prismas y paredes deben incluir sus correspondientes TAPAS DE CIERRE 
     en sus extremos (ej. Z=0 y Z=L). Si falta una tapa, la voxelización fallará.

[R2] RENDIMIENTO Y UNIFICACIÓN DE MALLAS:
     NUNCA crees instancias 'new Voxels()' dentro de un bucle 'for' o 'foreach' para
     luego hacer '.Add()'. Construye TODA la geometría usando un único objeto 'Mesh' 
     o 'Lattice', y conviértelo a 'Voxels' UNA SOLA VEZ fuera del bucle.

[R3] PROHIBICIONES Y DEPRECACIONES DE API:
     - NO uses 'VoxSubtract()'. El método correcto de PicoGK es 'Subtract()'.
     - NO utilices segmentos 'Lattice.AddBeam()' de longitud cero (pA == pB).
     - NO inviertas coordenadas Z (no utilices -z). Usa el eje Z cartesiano positivo.

3. ECUACIONES TÉCNICAS A IMPLEMENTAR
--------------------------------------------------------------------------------
1. Perfil del Radio Interno R(z):
   Si z <= Z_throat:
       R(z) = R_chamber + (R_throat - R_chamber) * sin((z / Z_throat) * (PI / 2))
   Si z > Z_throat:
       R(z) = R_throat + (R_exit - R_throat) * ((z - Z_throat) / (L_total - Z_throat))

2. Torsión Helicoidal del Canal n a cota z:
   Angle_n(z) = (n * 2 * PI / N_chan) + ((z / L_total) * 2 * PI * N_turns)
   HalfWidthAngle(z) = (w_c * 0.5) / R_in(z)

3. Alineación del Colector Toroidal:
   R_major = R(z) + (0.5 * t_wall)

--------------------------------------------------------------------------------
4. PATRÓN DE ENSAMBLE BOOLEANO EN TRES PASOS
--------------------------------------------------------------------------------
Siempre estructura el programa principal 'Program.cs' bajo este esquema:

    // 1. Dominio Sólido (Estructura)
    Voxels voxSolidShell = ThrusterGenerator.VoxBuildEngineShell(...);
    ManifoldResult inletManifold = ManifoldGenerator.CreateToroidalManifold(z: 0.0f, ...);
    ManifoldResult outletManifold = ManifoldGenerator.CreateToroidalManifold(z: fTotalHeight, ...);

    voxSolidShell.Add(inletManifold.VoxSolidShell);
    voxSolidShell.Add(outletManifold.VoxSolidShell);

    // 2. Dominio de Fluido (Vaciado Hidráulico)
    Voxels voxCoolant = RegenerativeCooling.VoxGenerateCoolingChannels(...);
    Voxels voxTotalFluid = voxCoolant;
    voxTotalFluid.Add(inletManifold.VoxFluidDomain);
    voxTotalFluid.Add(outletManifold.VoxFluidDomain);

    // 3. Vaciado Booleano Final y Exportación
    voxSolidShell.Subtract(voxTotalFluid);

    Mesh meshExport = new Mesh(voxSolidShell);
    meshExport.SaveToFile3Mf("Output_Engine.3mf");
