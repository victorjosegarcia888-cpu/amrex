SPACE X RAPTOR ENGINE — FULL PARAMETER & GEOMETRY SPEC
===========================================================

SOURCE: Wikipedia Raptor Engine + linked technical references
Propellant: LOX / CH4 (Methalox)
Cycle: Full-Flow Staged Combustion (FFSC)
Preburners: 2 (Fuel-Rich + Oxidizer-Rich)
Turbopumps: Dual-shaft, independent

-----------------------------------------------------------
10. FFSC GEOMETRY NOTES
-----------------------------------------------------------
- Both propellants arrive as hot gas → better mixing
- Preburners reduce turbine temperature
- Dual turbopumps reduce cavitation risk
- Subcooled propellants increase density
- Coaxial swirl injector (24–36 injectors)
- Regenerative cooling in chamber + nozzle

-----------------------------------------------------------
11. EQUATIONS FOR SCRIPTING
-----------------------------------------------------------

(1) Mass flow split:
mdot_total = mdot_ox + mdot_fuel

(2) Mixture ratio:
O/F = mdot_ox / mdot_fuel = 3.6

(3) Chamber pressure:
Pc = 330e5 Pa

(4) Thrust:
F = mdot_total * Ve + (Pe - Pa) * Ae

(5) Specific impulse:
Isp = Ve / g0

(6) Bell nozzle profile:
R(x) = a0 + a1*x + a2*x^2 + a3*x^3

(7) Cooling channel helix:
r(t) = R * cos(t)
z(t) = pitch * t

13. INSTRUCTIONS FOR DEVELOPING THE SCRIPT (.cs)
-----------------------------------------------------------

1. Create folder:
   examples/EngineFFSC/

2. Create files:
   RaptorParameters.cs
   ChamberFFSC_Raptor.cs
   Nozzle_Raptor3.cs
   Preburner_ORPB.cs
   Preburner_FRPB.cs
   Turbopump_Raptor.cs
   InjectorCoaxial.cs
   CoolingHelix.cs
   FFSC_Engine.cs
   Program.cs

3. Use libraries:
   PicoGK
   LEAP71.ShapeKernel
   LEAP71.LatticeLibrary
   LEAP71.QuasiCrystals
   LEAP71.HelixHeatX

4. Build geometry:
   - Bell nozzle profile using CreateBellNozzleProfile()
   - Sweep with SweepProfile()
   - Add cooling channels with HelixHeatX.CreateHelicalChannel()
   - Add lattice with QuasicrystalField()
   - Add injectors with coaxial swirl geometry
   - Add preburners with toroidal manifold
   - Add turbopump with helical inducer NASA TM X‑419

5. Assemble engine:
   engine.Add(Chamber)
   engine.Add(Nozzle)
   engine.Add(Preburners)
   engine.Add(Turbopumps)
   engine.Add(Injectors)
   engine.Subtract(CoolingChannels)

6. Export:
   Library.ExportMeshToStl()
   Library.ExportMeshTo3MF()
