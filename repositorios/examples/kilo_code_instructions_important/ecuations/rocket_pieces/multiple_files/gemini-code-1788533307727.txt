- R_throat = 0.045         // Radio de la garganta de la tobera (m)
- R_exit = 0.120           // Radio de salida de la tobera (m)

- L_nozzle = 0.350         // Longitud de la tobera (m)

[EQUACIONES]
1. Perfil Parabólico de la Tobera (Parabolas Conectadas):
   R(x) = R_throat + (R_exit - R_throat) * pow(x / L_nozzle, 2)

2. Estimación de Coeficiente Convectivo (Aproximación de Bartz):
   h_g = [ 0.026 / pow(D_t, 0.2) ] * (pow(mu, 0.2) * Cp / pow(Pr, 0.6)) * pow(P_c / c_star, 0.8) * pow(A_t / A, 0.9) * Sigma

3. Conductividad Térmica Efectiva en Matriz UHTC (ZrB2-SiC con Vidrio Borosilicato Autocurativo):
   k_eff = V_zrb2 * k_zrb2 + V_sic * k_sic + V_glass * k_glass * f_tortuosity

4. Campo Distancial Implícito (SDF) para Celda Gyroid TPMS (PikoGK Kernel):
   F_gyroid(x, y, z) = sin(2 * PI * x / L) * cos(2 * PI * y / L) + sin(2 * PI * y / L) * cos(2 * PI * z / L) + sin(2 * PI * z / L) * cos(2 * PI * x / L) - T
