01
Crear la arquitectura del proyecto
El agente debe generar un proyecto C# con dos archivos principales: EngineTasks.cs y Program.cs.
Crear solución .NET con un proyecto de consola.
Añadir referencias a PicoGK, PicoGK.Geometry y librerías auxiliares.
Crear archivo EngineTasks.cs para lógica geométrica.
Crear archivo Program.cs para orquestación del pipeline.

02
Implementar Task 1: Impulsor de Bomba de Combustible
Generar el impulsor paramétrico con hub cónico y 12 álabes helicoidales.
Parámetros: Dit=45mm, D2t=134mm, hb=2.5mm.
Crear hub cónico mediante campos implícitos.
Generar 12 álabes helicoidales con barrido.
Sustraer el pasaje central de inducción.
Devolver un objeto Voxels listo para ensamblaje.

03
Implementar Task 2: Rotor de Turbina de Oxidador
Construir el disco central y los 26 álabes axiales aerodinámicos.

Parámetros: diámetro medio=115.4mm, altura=12mm.
Crear disco central.
Distribuir 26 álabes según ángulos de velocidad.
Usar perfiles aerodinámicos paramétricos.
Devolver Voxels del rotor.

04
Implementar Task 3: Prequemador y Cárter
Generar cuerpo principal, colector toroidal y vaciados internos.
Crear cuerpo cilíndrico.
Añadir torus para manifold de combustible.
Vaciado de cámara interna.
Vaciado del resonador acústico anular.
Devolver Voxels del prequemador.

05
Implementar Task 4: Cámara de Combustión y Tobera
Construir geometría convergente-divergente paramétrica basada en perfiles cuadráticos.

Definir perfil 2D de cámara → garganta → salida.
Extruir a volumen implícito.
Vaciado del núcleo central.
Preparar para canales regenerativos.
Devolver Voxels de cámara+tobera.

06
Implementar Task 5: Tuberías de Alta Presión
Generar ductos paramétricos con trayectorias Bézier y juntas flexibles.
Conectar turbobombas con prequemador.
Usar curvas Bézier cúbicas.
Crear pared hueca (radio exterior – espesor).
Integrar bellows/corrugaciones.
Devolver Voxels de ductos.

07
Implementar Task 6: Canales de Refrigeración Regenerativa
Crear matriz de canales helicoidales siguiendo el perfil de la tobera.

Generar ~120 canales.
Aplicar torsión helicoidal (fHelixAngleDeg).
Sección rectangular/trapezoidal.
Sustraer canales del cuerpo principal.
Devolver Voxels de canales.

08
Orquestar todo en Program.cs
Program.cs debe ensamblar, filtrar y exportar el motor completo.

Configurar resolución de vóxel: 0.25–0.30mm.
Invocar cada Task de EngineTasks.
Ensamblar con Add/Subtract.
Aplicar OverOffset (+R → -R) para fillets.
Aplicar GaussianBlur para suavizar aliasing.
Extraer malla final: new Mesh(voxAssembly).
Exportar STL y 3MF.
Crear directorio de salida.

09
Integrar parámetros del motor ASE / Ursa Major
El agente debe usar los parámetros reales para validar geometrías.

RPM: 93,000.
Presiones: entrada 65 psia, salida 2230 psia.
Caudal: 628–669 gpm.
Eficiencia: 58%.
Geometría de cámara/tobera según figuras 4-22 y 4-23.

10
Mantener escalabilidad basada en vóxeles

Tratar cada componente como nube de puntos.
Permitir escalado radial/axial.
Aplicar deformaciones vectoriales.
Integrar geometrías aperiodicas.
Preparar para futuras pruebas en Rust.

Program.cs — Ensamblaje y exportación
El agente debe:

Configurar resolución global:

csharp
Library.Go(0.25);
var voxAssembly = new Voxels(0.25);
Invocar cada Task y posicionar:

csharp
var turbine = EngineTasks.Task_GenerateVectorTurbine();
turbine.Translate(0, 0, 0.25);
voxAssembly.Add(turbine);
Ensamblar todas las piezas:

csharp
voxAssembly.Add(EngineTasks.Task_GeneratePreburnerToroid());
voxAssembly.Add(EngineTasks.Task_GenerateFuelPumpImpeller());
voxAssembly.Add(EngineTasks.Task_GenerateAperiodicLattice());
voxAssembly.Subtract(EngineTasks.Task_GenerateCoolingChannels());
Aplicar filtros morfológicos:

csharp
voxAssembly.DoOffset(+0.003);
voxAssembly.DoOffset(-0.003);
voxAssembly.DoGaussianBlur(1.0);
Exportar malla:

csharp
var mesh = new Mesh(voxAssembly);
Library.ExportMeshToStl(mesh, "output/HybridRocketEngine.stl");
Library.ExportMeshTo3MF(mesh, "output/HybridRocketEngine.3mf");
Console.WriteLine("Motor híbrido compacto generado y exportado.");

OTROS ANALISIS RELEVANTES

Análisis de las piezas del Noyron TKL‑200
🔹 Tobera generativa (imagen 1 y 2)
Tipo: cámara + tobera regenerativa impresa en aluminio.

Medidas aproximadas: radio superior ≈ 40–60 mm, base ≈ 120–150 mm.

Espesor medio: 2–4 mm en paredes internas.

Canales: patrón ramificado tipo vascular lattice (LEAP71_LatticeLibrary).

Material: AlSi10Mg o CuCrZr, compatible con HelixHeatX para refrigeración.

🔹 Cámara de combustión (imagen 5 Excelsior)
Canales internos: helicoidales y paralelos, ideales para HelixHeatX.

Volumen útil: 0.5–1 L.

Geometría: aperiodica con simetría axial → usa LEAP71_QuasiCrystals.

Refrigeración: flujo regenerativo con combustible.

🔹 Conjunto turbobomba y ductos (imagen 3 y 6)
Componentes: bombas, válvulas, colectores.

Diámetros: 10–25 mm en ductos principales.

Espesores: 1–2 mm.

Geometría: tubular con curvatura spline → ShapeKernel y PicoGK.Geometry.

public static Voxels GenerateStealthEngine()
{
    var engine = new Voxels(0.25);

    // Turbina XA103 compactada
    var turbine = GenerateTurbine();
    turbine.Scale(new Vector3(0.70f, 0.70f, 0.85f));
    turbine.Deform(v => v * Math.Sin(v.z * 0.4));
    engine.Add(turbine);

    // Preburner ciclo cerrado
    var preburner = GeneratePreburner();
    preburner.Scale(new Vector3(0.85f, 0.85f, 1.0f));
    engine.Add(preburner);

    // Inyectores helicoidales
    engine.Add(GenerateInjectorsStealth());

    // Cámara stealth compacta
    var chamber = GenerateNoyronAdvancedChamber();
    engine.Add(chamber);

    // Canales regenerativos densos
    engine.Subtract(GenerateCoolingChannels());

    // Tobera stealth variable
    engine.Add(GenerateVariableStealthNozzle());

    // Lattice stealth interno
    engine.Add(GenerateStealthLattice());

    return engine;
}
⭐ B) CÁMARA DE COMBUSTIÓN NOYRON POTENTE
(basada en PDF “motor” + Noyron TKL‑200 + LEAP71)

csharp
public static Voxels GenerateNoyronAdvancedChamber()
{
    var P = EngineDatabase.ChamberNoyron;

    var profile = ShapeKernel.CreateBellNozzleProfile(
        P["Dc"], P["Dt"], P["De"],
        P["thetaIn"], P["thetaExp"], P["thetaExit"]
    );

    var mesh = ShapeKernel.SweepProfile(profile, P["wallThickness"]);
    var vox = new Voxels(mesh);

    // Geometría Noyron (PDF motor)
    vox.Deform(v => v * Math.Sin(v.z * 0.8) * Math.Cos(v.x * 0.5));

    // Lattice interno estilo LEAP71
    vox.Modulate(QuasiCrystals.CreateQuasicrystalField(16, 0.030, 14.0));

    // Compactación orbital
    vox.Scale(new Vector3(0.85f, 0.85f, 0.75f));

    return vox;
}
